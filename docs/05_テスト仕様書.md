# 05 テスト仕様書

自動テスト：`tests/`（pytest）。実行：`.\.venv\Scripts\python.exe -m pytest`
テストは毎回メモリ上の DB（画面のテストは一時フォルダの DB）を使い、本物のデータには触れない。

## 実施結果

| 日付 | 環境 | 結果 |
| --- | --- | --- |
| 2026-11-23 | Windows 11 Pro・Python 3.11.1・Streamlit 1.67.0・SQLAlchemy 2.1.9・pandas 3.1.1・pytest 9.2.0 | **83 件すべて成功**（約 13 秒） |

テストで見つかって直した不具合：pandas 3 では文字の列が `object` 型ではなくなったため、CSV の数式インジェクション対策が効いていなかった（UT-17 で発見 → 「数値でない列すべて」を対象に修正）。
